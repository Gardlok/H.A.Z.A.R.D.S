# Kitchen lexicon

HAZARDS uses clear upstream application names in user-facing output and
culinary aliases for their integration directories. The joke must never obscure
which application owns a responsibility.

| Ingredient | Source | Meaning |
| --- | --- | --- |
| `helixer` | Helix + elixir | Helix configuration and editor integration |
| `alacarte` | Alacritty + à la carte | Local terminal configuration |
| `zellijuice` | Zellij + juice | Zellij configuration and layouts |
| `arsenallspice` | Arsenal + allspice | Pillar and supporting-tool registry |
| `rhaisour` | Rhai/rye + sour | Sandboxed automation starter culture |
| `dotterbatter` | Dotter + batter | Dotter deployment mappings |
| `surrelish` | SurrealDB + relish | Dynamic workspace metadata schema |

The aliases originated in the 2023 prototype, where `helixer`, `zellijuice`,
`rhaisour`, and `recipe.plan` appeared together. This file exists because
future maintainers should not need Git archaeology to understand a bread pun.
